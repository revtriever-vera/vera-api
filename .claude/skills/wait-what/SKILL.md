Adapted from mattpocock/skills@4ae2317 `skills/productivity/wait-what/` (MIT, licence in `skills/LICENSE-mattpocock-skills` of this repository). Adaptations: the agent reaches it on its own, in pt-BR, with the domain words of the product.

The last message did not land. Re-pitch it; saying the same thing again is not a re-pitch.

1. Open with what the person needs to know or decide, in one sentence.
2. Give the context they were missing: say what each thing does for whoever uses Vera before using any name coined during the work.
3. Write plain pt-BR in short sentences, one idea each, with the domain words of the product (patrimônio, gastos, contas, metas). A technical term comes with its meaning beside it.
4. Close with the decision that is theirs, when there is one.

If you cannot say it plainly, you have not understood it yet: go back to the source before answering.
